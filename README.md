85 XML material descriptor files covering material formats across

## [Hashing](reference/watch_dogs/hashing.md)

CRC32 / FNV32 / FNV64 — little- and big-endian variants used by the
Disrupt engine for file/object naming.

## [Watch Dogs Community Tools](reference/watch_dogs/community-resources.md)

Third-party tools (HavokLib, OpenDogs, Volfin importer) and ZModeler forum
knowledge — format confirmations and gameplay semantics for the Disrupt
reference work.

## [Bethesda Engine References](reference/index.md)

Havok-based animation RE for Skyrim (hkxcmd/KF pipeline), Fallout 4 (behavior
workflow), and Starfield (CE2/SFSE), plus the UE5 + Gamebryo hybrid Oblivion
Remastered reference.
