Watch Dogs Reference

Formats​

  • HKX Collision Format — WD1/WD2 (Ubisoft's Havok fork) general overview
  • WD2 TAG0 Collision Format — Havok 2015.1 compendium: item/fixup tables, shape graph, 11:11:10 quant decode, hkx vs .phys type tables
  • Packfile Format — old packfile (Havok 2012) + TAG0 chunk format, fixup resolution
  • FAT/DAT Archive Format — FAT2/FAT3/FAT5 variants, entry layouts, hash differences, .nfo pairing
  • Compressed Mesh Format — hkpBvCompressedMeshTree structure, section/primitive/dataRun layout
  • Injection Internals — WD1/WD2 HKX injection pipelines, format differences
  • MAC Binary Format — source animation clip format (curves, skeleton, events, recursive parts)
  • MAB Animation Format — compiled runtime animation (Oodle compressed, quantized u8 curves)
  • Markup XML Format — event definitions referencing MAC files (footsteps, sounds, attacks)
  • XBG Model Format (GeomParser Decompile) — header, hierarchy, mesh write order, bone mapping, channel refs
  • Material Hex Editing — Razor tool, CRC32 lookup, hex workflow, converter bugs
  • Material Binary Format — TAM\0 v7/v15 structure, param command types, ConvertMaterials.exe XML editing workflow
  • XBT Texture Format — TBX header structure, _high texture system, hex analysis, hV_WD1ModdingKit workflow
  • BFD Sprite Atlas Format — UI icon mappings, paired with XBT textures, percentage-based coordinates
  • SPK Sound Package Format — Wwise audio wrapper, header fields, bus IDs, music library integration
  • Hashing (CRC32 / CRC64_WD2)
  • FEU Format (Flash UI) — SWF with UEF header, JPEXS editing, AS2 UI class hierarchy, Linux conversion
  • Entity XML Structure — prototype format, hash field conventions, components
  • Material Descriptors — shader parameter schema XMLs (94 in leak, 46 in WD1)

Research​

  • Lighting Pipeline Hooks — renderer queue RVAs, GPU light structs (SSunLight/SOmniLight/SSpotLight), LightData CB, GI probes

  • SSRTGI Project — D3D11 screen-space GI ASI: UpdateCamera RVA (0x170ED50), vtable indices, HDR pre-tonemap composite, light-capture hook status

  • Player Watch Component — cut early-alpha wristwatch component (Feb 2012), fixed-speed seconds hand

  • Havok Repos — GitHub/GitLab repos with HKX parsing (hkparse, HKX2, BlenderAddon, etc.)

  • Decompiled DLLs — IDA Hex-Rays output from Ubisoft leak (GeomParser, DuniaDemo, gxasset, etc.)
